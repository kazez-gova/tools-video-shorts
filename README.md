# Tools Video Shorts

Kumpulan skrip Python sederhana untuk mempercepat alur kerja pembuatan konten video Shorts.

## Daftar Fitur

 Menghitung estimasi durasi baca naskah agar pas dengan batas waktu video singkat.
 Memecah paragraf panjang menjadi daftar kalimat pendek per baris agar lebih mudah dibaca saat perekaman voice-over.
 Menyusun format deskripsi dan kumpulan hashtag otomatis berdasarkan judul serta kata kunci topik.
 Mengukur jumlah kata dan estimasi waktu kalimat pembuka agar padat di bawah 3 detik pertama.
 Menyimpan draf ide judul dan hook video beserta catatan waktu ke file teks lokal.

## Cara Menjalankan

Buka terminal di dalam folder proyek, lalu jalankan skrip yang diinginkan dengan perintah `python nama_file.py`.
