# Tools Video Shorts

Kumpulan skrip Python sederhana untuk mempercepat alur kerja pembuatan konten video Shorts.

## Daftar Fitur

1. **`main.py`** — Menu utama interaktif untuk menjalankan seluruh skrip utilitas dari satu tempat.
2. **`hitung_durasi.py`** — Menghitung estimasi durasi baca naskah agar pas dengan batas waktu video singkat.
3. **`pecah_naskah.py`** — Memecah paragraf panjang menjadi daftar kalimat pendek per baris agar lebih mudah dibaca saat perekaman voice-over.
4. **`template_deskripsi.py`** — Menyusun format deskripsi dan kumpulan hashtag otomatis berdasarkan judul serta kata kunci topik.
5. **`cek_hook.py`** — Mengukur jumlah kata dan estimasi waktu kalimat pembuka agar padat di bawah 3 detik pertama.
6. **`catatan_ide.py`** — Menyimpan draf ide judul dan hook video beserta catatan waktu ke file teks lokal.
7. **`cek_judul.py`** — Mengecek panjang karakter judul agar tidak terpotong saat tampil di layar HP.
8. **`cari_ide.py`** — Mencari dan menampilkan kembali draf ide konten yang tersimpan di file teks lokal berdasarkan kata kunci.

## Cara Menjalankan

Buka terminal di dalam folder proyek, lalu jalankan menu utama dengan perintah `python main.py` atau jalankan skrip satuan dengan `python nama_file.py`.
