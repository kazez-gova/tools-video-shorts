# Tools Video Shorts

Kumpulan skrip Python sederhana untuk mempercepat alur kerja pembuatan konten video Shorts.

## Daftar Fitur

1. **`hitung_durasi.py`** [G Menghitung estimasi durasi baca naskah agar pas dengan batas waktu video singkat.
2. **`pecah_naskah.py`** [G Memecah paragraf panjang menjadi daftar kalimat pendek per baris agar lebih mudah dibaca saat perekaman voice-over.
3. **`template_deskripsi.py`** [G Menyusun format deskripsi dan kumpulan hashtag otomatis berdasarkan judul serta kata kunci topik.
4. **`cek_hook.py`** [G Mengukur jumlah kata dan estimasi waktu kalimat pembuka agar padat di bawah 3 detik pertama.
5. **`catatan_ide.py`** [G Menyimpan draf ide judul dan hook video beserta catatan waktu ke file teks lokal.

## Cara Menjalankan

Buka terminal di dalam folder proyek, lalu jalankan skrip yang diinginkan dengan perintah `python nama_file.py`.
