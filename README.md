# Tools Video Shorts

Kumpulan skrip Python sederhana untuk mempercepat alur kerja pembuatan konten video Shorts.

## Daftar Fitur

1. **`hitung_durasi.py`** — Menghitung estimasi durasi baca naskah agar pas dengan batas waktu video singkat.
2. **`pecah_naskah.py`** — Memecah paragraf panjang menjadi daftar kalimat pendek per baris agar lebih mudah dibaca saat perekaman voice-over.
3. **`template_deskripsi.py`** — Menyusun format deskripsi dan kumpulan hashtag otomatis berdasarkan judul serta kata kunci topik.
4. **`cek_hook.py`** — Mengukur jumlah kata dan estimasi waktu kalimat pembuka agar padat di bawah 3 detik pertama.

## Cara Menjalankan

Buka terminal di dalam folder proyek, lalu jalankan skrip yang diinginkan dengan perintah `python nama_file.py`.
